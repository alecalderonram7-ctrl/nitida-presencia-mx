# Nítida · demo pública

Muestra interactiva de páginas profesionales para salud, diseño, arquitectura e ingeniería.

## Qué puedes probar

- Selector de sector y navegación a cada página de muestra.
- Filtros y módulos interactivos de cada demo.
- Detalles de paquetes y carrito guardado en el navegador.
- Vista de selección con desglose de precios.

## Alcance de esta demo

Esta publicación estática en GitHub Pages no tiene servidor, autenticación ni procesamiento de pagos. El carrito y la vista de selección sirven para explorar la experiencia: no se envían pedidos, no se cobran importes y los botones de contacto no envían mensajes. Los precios son ejemplos de la propuesta y no constituyen una cotización ni contrato.

Los perfiles, nombres, credenciales, proyectos y testimonios de muestra son ficticios. Las imágenes fueron generadas para esta demostración.
